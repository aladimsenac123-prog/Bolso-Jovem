# Bolso-Jovem

Aplicativo mobile nativo (Kotlin & Jetpack Compose) com estética Apple HIG para o **Bolso Jovem (PixControl)**.

## Visão Geral
Projeto desenvolvido com foco em controle financeiro jovem e transações Pix simplificadas, arquitetura limpa e UI moderna.

## Sincronização e Deploy Contínuo
Este repositório possui monitoramento contínuo para sincronização e deploy automático de alterações.
